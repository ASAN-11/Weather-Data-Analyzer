# Weather Data Analyzer

🚧 **Status: Under Development**

**Weather Data Analyzer** is an R-based project designed to analyze temperature and rainfall data using statistical methods and visualization.

## About

The project explores weather datasets to identify patterns and summarize temperature and rainfall information through statistical analysis and graphical visualization.

## Core Idea

* 🌡️ Analyze temperature data
* 🌧️ Analyze rainfall patterns
* 📊 Apply statistical methods
* 📈 Visualize weather data
* 🧮 Practice data analysis in R

## Tech Stack

* R

## Development

The project is currently under development, with statistical analysis methods and weather-data visualizations being explored and refined.
